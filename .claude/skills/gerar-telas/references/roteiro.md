# Formato do roteiro

```
DD/MM                      ← data da edição (1ª linha)

1. <Título do ponto> <texto falado pelo locutor...>

2. <Título do ponto> <texto...>
...
```

- Cada ponto começa com `N.` seguido de um título curto e do texto corrido, na mesma linha.
- O título não tem separador explícito do texto: em geral são as primeiras 1–4 palavras
  (ex.: `Culto de Domingo`, `Classe Bíblica de quarta`, `ASA`). Na dúvida, confirme com o usuário.
- **Ano:** use sempre o **ano atual** (data de hoje), para a data da edição e para qualquer data
  ou evento citado no roteiro. Só use outro ano se ele estiver **escrito explicitamente** no
  roteiro (ex.: `31/10/2027`, "Mutirão de Natal 2027"). Nunca deduza o ano pelos exemplos.
- Pontos fixos que costumam aparecer: Abertura, Comunidade (WhatsApp), Secretaria, Encerramento, Conclusão.
